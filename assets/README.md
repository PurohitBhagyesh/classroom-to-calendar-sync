# 📸 Assets & Screenshots Guide

Place your demo screenshots and media in this folder to be displayed in the main [`README.md`](../README.md).

## Recommended Image Names & Formats:

1. **`banner.svg` / `banner.png`** (1200x400 px)
   - The top hero banner for the GitHub repository.

2. **`calendar-preview.png`** (1920x1080 px or cropped)
   - Screenshot showing Google Calendar with the generated `"Google Classroom Deadlines"` calendar events and popup reminders.

3. **`cli-demo.png`** (800x600 px or terminal capture)
   - Screenshot of the rich CLI terminal output when running `python main.py sync`.

4. **`solution-pdf-preview.png`** (800x1000 px)
   - Screenshot of a generated Gemini AI solution PDF document.

## How to add your screenshots:
Simply save your image files directly into this `/assets` directory with the names above, commit, and push to GitHub:
```bash
git add assets/
git commit -m "docs: add demo screenshots"
git push origin main
```
